# RoleFit-AI Resume Template Sources

The following source archives were supplied by the project owner and are preserved here as design/structure references:

- `sources/jakes-resume/` — Jake's Resume LaTeX source
- `sources/faangpath/` — FAANGPath `resume.cls` and example `.tex`
- `sources/awesome-cv/` — Awesome-CV class source
- `sources/rendercv/` — RenderCV LaTeX source

RoleFit-AI generates **editable DOCX** files from structured resume text. The DOCX renderer uses these supplied sources as visual/structural references rather than requiring a local LaTeX installation at runtime. This keeps the hackathon demo portable while preserving the editable output requirement.
